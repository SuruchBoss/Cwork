# ให้บทบาทกับบัญชีผู้ใช้

คู่มือนี้สำหรับผู้ดูแลระบบหรือผู้จัดการฝ่ายบุคคลที่ต้องให้เจ้าหน้าที่ฝ่ายบุคคล
เจ้าหน้าที่เงินเดือน หรือหัวหน้างาน ใช้เมนูที่พนักงานทั่วไปไม่เห็น

## ก่อนเริ่ม

- ต้องเป็นบัญชีที่มีสิทธิ์ `role:manage` ซึ่งผู้ดูแลระบบสูงสุดและผู้จัดการฝ่ายบุคคลมีอยู่แล้ว
- พนักงานคนนั้นต้องมีบัญชีผู้ใช้ก่อน ถ้ายังไม่มี การ์ดจะบอกว่ายังให้บทบาทไม่ได้

## ให้บทบาท

1. ไปที่เมนู **ทะเบียนพนักงาน** แล้วเปิดพนักงานคนนั้น
2. ที่การ์ด **บทบาทของบัญชี** กด **ให้บทบาท**
3. เลือกบทบาท ถ้าเป็นบทบาทที่เห็นพนักงานทั้งบริษัท เช่น เจ้าหน้าที่ฝ่ายบุคคล
   จะเลือกจำกัดไว้แผนกเดียวได้ ถ้าให้ชั่วคราว ใส่วันสุดท้ายไว้ด้วย
4. กด **ให้บทบาท**

**การจำกัดแผนกไม่ได้จำกัดทุกอย่าง** มันกรองเฉพาะข้อมูลพนักงานกับสิ่งที่ผูกกับพนักงาน
(การลา เวลาทำงาน ล่วงเวลา ค่าใช้จ่าย ผลงาน เอกสาร) ส่วนเงินเดือน (รอบจ่าย สลิป สลิปที่พิมพ์
ใบรับเงิน ค่าตอบแทนรายคน) ใบลาออก และบันทึกการใช้งานระบบ ใครมีสิทธิ์ก็เห็นของทุกแผนก
เช่น เจ้าหน้าที่เงินเดือนที่จำกัดไว้แผนกเดียวก็ยังเห็นเงินเดือนของทุกแผนก ระบบจะขึ้น
ข้อความเตือนตอนเลือกแผนก ถ้าต้องการกันเงินเดือนของแผนกอื่น การจำกัดแผนกยังทำแทนไม่ได้

ระบบจะออกจากระบบให้เขาทุกเครื่องทันที พอเข้าสู่ระบบใหม่ก็จะเห็นเมนูตามบทบาทใหม่

บทบาทที่เห็นเลขบัตรประชาชน จ่ายเงิน หรือให้บทบาทคนอื่นได้ (เจ้าหน้าที่เงินเดือน
ผู้จัดการฝ่ายบุคคล ผู้ดูแลระบบสูงสุด) ต้องยืนยันตัวตนสองชั้น ถ้าเขายังไม่เคยตั้งค่า
ระบบจะพาตั้งค่าตอนเข้าสู่ระบบครั้งถัดไป ให้เตรียมแอปยืนยันตัวตนในมือถือไว้

## ถอนบทบาท

กด **ถอนบทบาท** ที่บทบาทนั้นแล้วยืนยัน ระบบจะออกจากระบบให้เขาทุกเครื่อง
และเมนูของบทบาทนั้นจะหายไปตั้งแต่เข้าสู่ระบบครั้งถัดไป

## สิ่งที่ระบบไม่ยอม

- ให้หรือถอนได้เฉพาะบทบาทที่ตัวเองมีสิทธิ์ครบทุกข้อ ผู้จัดการฝ่ายบุคคลจึงตั้งใคร
  เป็นผู้ดูแลระบบสูงสุดไม่ได้
- ถอนสิทธิ์จัดการบทบาทของตัวเองไม่ได้
- ถอนผู้ดูแลระบบสูงสุดคนสุดท้ายไม่ได้ ต้องตั้งคนอื่นก่อน

ทุกครั้งที่ให้หรือถอนบทบาทจะถูกบันทึกในประวัติการใช้งาน ว่าใครให้บทบาทอะไรกับใคร

## สิ่งที่ยังต้องทำในฐานข้อมูล

การเปลี่ยนว่าบทบาทหนึ่งทำอะไรได้บ้าง หรือสร้างบทบาทใหม่ ยังไม่มีหน้าจอ ผู้ติดตั้งระบบ
ต้องทำตาม `docs/operations.md` หัวข้อ "Giving a role a permission"
