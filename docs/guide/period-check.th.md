# ส่งเดือนให้นักบัญชี และเทียบกับที่ยื่นไปแล้ว

คู่มือนี้สำหรับบริษัทที่จ้างสำนักงานบัญชีข้างนอกยื่น ภ.ง.ด.1 ให้ ต้องมีสิทธิ์ส่งออกเงินเดือน
(`payroll:export`) งวดนั้นต้องอนุมัติครบทุกรอบ (run) และตัวเลขรวมต้องตรงกัน ถ้าไม่ตรง Cwork จะบอกว่ารอบไหนมีปัญหาและไม่ส่งไฟล์ให้

## ส่งไฟล์ให้นักบัญชี

1. เมนู **เงินเดือน** ในแถวของงวดที่ต้องการ กด **ส่งออกสำหรับนักบัญชี**
2. ได้ไฟล์ CSV เปิดใน Excel ได้ มีทุกคอลัมน์เหมือน **ส่งออก CSV** ปกติ และเพิ่มสองคอลัมน์ท้ายแถว

| คอลัมน์ | คืออะไร |
|---|---|
| Tax ID | เลขประจำตัวผู้เสียภาษีของพนักงาน ถ้าไม่ได้เก็บเลขภาษีไว้แยก ใช้เลขบัตรประชาชน (คนไทยใช้เลขเดียวกัน) ถ้าไม่มีทั้งสองอย่างจะว่างไว้ |
| Income type | ประเภทเงินได้ เป็น `40(1)` ทุกแถว เพราะเงินเดือนใน Cwork คำนวณเฉพาะเงินได้จากการจ้างงาน (เงินเดือน ค่าล่วงเวลา โบนัส) |

ก่อนส่ง ลองไล่ดูคอลัมน์ Tax ID ว่ามีช่องว่างไหม พนักงานที่ว่างต้องเติมเลขในข้อมูลพนักงานก่อน
ไฟล์นี้มีเลขประจำตัวของพนักงานจริง ส่งผ่านช่องทางที่ปลอดภัย และอย่าเก็บทิ้งไว้ในที่ที่คนอื่นเปิดได้
การส่งออกแต่ละครั้งถูกบันทึกในบันทึกการตรวจสอบ (เป็นจำนวนแถว ไม่มีเลขใดๆ)

## ส่งทะเบียนเงินเดือนประจำเดือน

ทะเบียนเงินเดือนคือตารางหน้าเดียวที่ HR ส่งให้นักบัญชีทุกเดือน ไฟล์นี้ทำให้ในรูปแบบเดียวกัน คนละไฟล์กับ **ส่งออกสำหรับนักบัญชี** (ไฟล์นั้นไว้คีย์ ภ.ง.ด.1 มีเลขประจำตัวผู้เสียภาษี)
ถ้าสิ่งที่ส่งทุกเดือนคือทะเบียน ให้ส่งไฟล์นี้ ไม่ต้องส่งไฟล์ CSV

1. เมนู **เงินเดือน** ในแถวของงวดใดก็ได้ของเดือนนั้น กด **ส่งออกทะเบียนเงินเดือน**
2. ได้ไฟล์ Excel ชื่อ `payroll-register-ปี-เดือน.xlsx` ไฟล์เดียวต่อเดือน รวมทุกคนที่จ่ายในเดือนนั้น
   พนักงานรายเดือนอยู่ในงวดรายเดือน พนักงานรายวันอยู่ในงวดครึ่งเดือนสองงวด ทะเบียนรวมให้ครบสามงวด คนเดียวกันที่จ่ายสองครึ่งจะรวมเป็นแถวเดียว
   ถ้าจ่ายรายวันทุก 14 วัน ทะเบียนรวมทุกงวด 14 วันที่นับเป็นเดือนนั้น (สองหรือสามงวด) และจะรอจนกว่างวดสุดท้ายของเดือนจะมีรอบที่อนุมัติแล้ว
3. เดือนที่ยังไม่ครบจะไม่ส่งไฟล์ให้ และบอกว่าขาดอะไร เช่น งวดไหนยังไม่มีรอบ รอบไหนยังไม่อนุมัติ หรือยังไม่มีงวดครึ่งหลังของค่าจ้างรายวัน
   (ทะเบียนที่ขาดครึ่งเดือนหลังดูเหมือนเสร็จแล้วแต่ตัวเลขน้อยกว่าจริง จึงไม่ปล่อย)

แผ่นแรก **ทะเบียนเงินเดือน** เรียงคอลัมน์ตามแบบฟอร์มของ HR:

| คอลัมน์ | คืออะไร |
|---|---|
| ลำดับที่, ชื่อ-สกุล | เรียงตามรหัสพนักงาน แถวสุดท้ายเป็น **รวม** |
| เงินเดือน | เงินเดือนที่จ่ายจริงในเดือนนั้น (ถ้าทำงานไม่เต็มเดือนคือยอดตามส่วน) ว่างสำหรับพนักงานรายวัน |
| ค่าแรงรายวัน: วันละ / จำนวนวันทำงาน / จำนวนเงิน | คูณกันได้ตามนั้น ว่างสำหรับพนักงานรายเดือน ถ้าสองครึ่งเดือนจ่ายอัตราต่างกัน ช่อง วันละ จะว่าง |
| โอที | รวมค่าล่วงเวลาทุกประเภท |
| อื่นๆ (ระบุ) ฝั่งเงินได้ | เงินได้อื่นทั้งหมดรวมกัน เช่น ค่าที่พัก โบนัส |
| รวมเงินได้ | เท่ากับยอดรวมเงินได้ในสลิป |
| ภาษี, ประกันสังคม | ภาษีหัก ณ ที่จ่าย และประกันสังคมส่วนลูกจ้างเท่านั้น |
| อื่นๆ (ระบุ) ฝั่งรายการหัก | รายการหักอื่นทั้งหมดรวมกัน เช่น กองทุนสำรองเลี้ยงชีพ เงินกู้ เงินเบิกล่วงหน้า |
| รวมหัก, รวมเงินได้สุทธิ | เท่ากับในสลิป |
| รายละเอียดอื่นๆ | คอลัมน์สุดท้าย ไม่อยู่ในแบบฟอร์มกระดาษ บอกว่าสองช่อง อื่นๆ (ระบุ) ประกอบด้วยรายการอะไร เท่าไร เช่น `เงินได้อื่นๆ: ค่าที่พัก 1,000.00; โบนัส 2,000.00 | หักอื่นๆ: เงินกู้ 500.00` |

ตัวเลขเก็บถึงสตางค์ตามที่ Cwork คำนวณ ไม่ปัดเศษ ไฟล์นี้ **ไม่มี** เลขบัตรประชาชน เลขผู้เสียภาษี เลขบัญชีธนาคาร และไม่มีส่วนของนายจ้าง
ส่วนประกันสังคมของนายจ้าง (ถ้านักบัญชีขอ) อยู่ที่แผ่นที่สอง **สรุปยอด** เป็นยอดรวมของเดือน ไม่ใช่รายคน
การส่งออกถูกบันทึกในบันทึกการตรวจสอบ (ชนิดไฟล์ งวดที่อ่าน และจำนวนแถว ไม่มีตัวเลขเงิน)

## เทียบกับยอดที่ยื่นไปแล้ว

1. เมนู **เงินเดือน** กด **เทียบกับที่ยื่นไปแล้ว** เลือกงวด
2. พิมพ์ยอด **ภาษีหัก ณ ที่จ่าย** ที่ e-Filing ออกให้ และ/หรือยอด **ประกันสังคม** ที่ยื่น (ส่วนลูกจ้างกับส่วนนายจ้างรวมกัน
   ตามที่ยื่นจริง) พิมพ์ลูกน้ำได้ เช่น `1,250.00` ใส่อย่างเดียวก็ได้
3. กด **เทียบ** จะเห็นยอดของ Cwork ยอดที่ยื่น และผลต่าง **ต่างแค่ 1 สตางค์ก็ขึ้นว่าไม่ตรง**
   ผลต่างเป็นยอดที่ยื่นลบยอดของ Cwork ถ้าเป็นบวกแปลว่ายื่นมากกว่าที่ Cwork คำนวณ

ถ้าไม่ตรง ให้ถามนักบัญชีก่อนว่ายื่นจากไฟล์ไหน และเดือนไหน แล้วค่อยหาว่าต่างตรงไหน ตัวเลขของ Cwork เป็นยอดที่สลิปหักจริง

## รันคู่ขนานกับวิธีเดิมของ HR

ใช้ตอนเริ่มใช้ Cwork ครั้งแรก เพื่อดูว่าตัวเลขที่ Cwork คำนวณตรงกับที่ HR ทำด้วยวิธีเดิมหรือเปล่า

1. เตรียมไฟล์ Excel หรือ CSV หนึ่งแถวต่อคน มีคอลัมน์ **รหัสพนักงาน, รายได้, ภาษี, ประกันสังคม, สุทธิ**
   กรอกครบทุกช่อง (ช่องว่างไม่ถือเป็น 0) ปัดเศษเป็นสตางค์แล้ว คอลัมน์อื่นในไฟล์จะถูกข้าม
   ประกันสังคมให้ใส่ส่วนของลูกจ้างเท่านั้น
2. ในหน้าเดียวกัน เลือกไฟล์ในข้อ 2
3. ได้ตารางที่ทำเครื่องหมายทุกคนและทุกคอลัมน์ที่ต่างกัน พร้อมผลต่างเป็นสตางค์ มีปุ่มแสดงทุกคนหรือเฉพาะคนที่ต่าง
   และบอกคนที่มีแค่ในไฟล์ของคุณ หรือมีแค่ใน Cwork

ไฟล์ที่อัปโหลดใช้เปรียบเทียบเท่านั้น Cwork ไม่เก็บและ **ไม่แก้สลิปเลย** ถ้ามีบรรทัดที่อ่านไม่ได้ จะบอกเลขแถวกับคอลัมน์ ให้แก้ในไฟล์แล้วอัปโหลดใหม่
คนที่ได้เงินในงวดนี้หลายรอบจะถูกรวมยอดทุกรอบก่อนเทียบ
