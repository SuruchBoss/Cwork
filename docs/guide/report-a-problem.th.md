# แจ้งปัญหา

คู่มือนี้สำหรับทุกคนที่ใช้คอนโซล Cwork เมื่อเจอข้อผิดพลาดหรือหน้าจอที่ทำงานผิดปกติ
และต้องการบอกคนที่ดูแลระบบให้ได้ข้อมูลครบโดยไม่ต้องเล่าซ้ำหลายรอบ

## ทำอย่างไร

1. เมนูซ้าย หมวด **ช่วยเหลือ** เลือก **แจ้งปัญหา** (ควรทำทันทีหลังเจอปัญหา
   ก่อนไปเปิดหน้าอื่นหลายหน้า เพราะ Cwork จำคำขอที่ล้มเหลวล่าสุดไว้แค่ 10 รายการ)
2. เล่าว่ากำลังทำอะไรอยู่และเห็นอะไร
3. กด **คัดลอกรายงาน** แล้ววางลงในข้อความ หรือกด **บันทึกเป็นไฟล์** แล้วแนบไฟล์
4. ส่งเองให้ผู้ดูแลระบบ เช่นทาง LINE หรืออีเมล ช่องทางส่งที่ใช้จริงยังไม่กำหนด
   หน้าจอจึงเขียนว่า "ยังไม่กำหนด" ถามผู้ดูแลระบบของบริษัทว่าให้ส่งที่ไหน

## Cwork ไม่ส่งอะไรออกไปเอง

หน้านี้ไม่มีปุ่มส่งและไม่เรียกเซิร์ฟเวอร์ใดๆ รายงานอยู่ในเบราว์เซอร์ของคุณจนกว่าคุณจะคัดลอก
หรือบันทึกเอง เมื่อปิดแท็บ รายการคำขอที่ล้มเหลวที่จำไว้ก็หายไปด้วย

## รายงานมีอะไรบ้าง

ส่วนแรกคือสิ่งที่คุณเขียน ส่งไปตามที่เขียนทุกตัวอักษร **กรุณาอย่าเขียนชื่อ เลขบัตรประชาชน
หรือเงินเดือน** เล่าแค่ว่าทำอะไรและเห็นอะไร

ส่วนที่สองคือสิ่งที่ Cwork แนบให้ ดูได้บนหน้าจอก่อนคัดลอก ประกอบด้วย

- เวอร์ชันของคอนโซล
- หน้าจอที่คุณอยู่ เช่น `/payroll/runs/:id` (ส่วนที่เป็นรหัสหรือชื่อจะถูกแทนด้วย `:id`)
- เวลาและเขตเวลา เบราว์เซอร์ และภาษา
- คำขอที่ล้มเหลวล่าสุดไม่เกิน 10 รายการ แต่ละรายการมีเส้นทาง ชื่อพารามิเตอร์ (ไม่มีค่า)
  สถานะ รหัสข้อผิดพลาด และรหัสคำขอ ซึ่งผู้ดูแลใช้ค้นหาในบันทึกของระบบได้

ไม่มีชื่อ เลขบัตรประชาชน เงินเดือน ข้อความของข้อผิดพลาด หรือข้อมูลที่กรอกในแบบฟอร์ม
(ข้อความของข้อผิดพลาดบางครั้งมีชื่อคน จึงไม่แนบ)

## ถ้าเบราว์เซอร์คัดลอกให้ไม่ได้

เบราว์เซอร์บางตัวไม่ให้คัดลอกเมื่อเปิดผ่าน HTTP หน้าจอจะบอก และแสดงข้อความทั้งหมดในกล่อง
ให้เลือกไปคัดลอกเอง หรือกดบันทึกเป็นไฟล์แทน
