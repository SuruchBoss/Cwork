# ส่วนต่างประกันสังคมจากเพดานค่าจ้างใหม่

คู่มือนี้สำหรับฝ่ายบุคคลหรือฝ่ายเงินเดือนที่จ่ายเงินเดือนปี 2569 ด้วย Cwork รุ่นก่อน
CW-075 ซึ่งยังคิดประกันสังคมบนเพดานเดิม 15,000 บาท

## เกิดอะไรขึ้น

กฎกระทรวงกำหนดค่าจ้างที่ใช้เป็นฐานในการคำนวณเงินสมทบ (ราชกิจจานุเบกษา เล่ม ๑๔๒
ตอนที่ ๘๑ ก วันที่ ๑๒ ธันวาคม ๒๕๖๘ หน้า ๕–๖) ปรับเพดานค่าจ้างตามมาตรา 33

| ปี           | เพดานค่าจ้าง | หักสูงสุดต่อเดือน |
| ------------ | ------------ | ----------------- |
| 2569 – 2571  | 17,500 บาท   | 875 บาท           |
| 2572 – 2574  | 20,000 บาท   | 1,000 บาท         |
| ตั้งแต่ 2575 | 23,000 บาท   | 1,150 บาท         |

ขั้นต่ำยังเป็น 1,650 บาทเท่าเดิม Cwork รุ่นนี้คิดตามเพดานของปีที่งวดนั้นอยู่ และเลิก
หยุดหักเมื่อครบ 9,000 บาทต่อปีแล้ว รอบที่คำนวณหลังอัปเดตจึงถูกต้องเอง

ส่วนรอบที่ล็อกหรือจ่ายไปแล้ว Cwork **ไม่แก้ย้อนหลัง** พนักงานที่ค่าจ้างเกิน 15,000 บาท
ถูกหักน้อยไปเดือนละไม่เกิน 125 บาท และนายจ้างสมทบน้อยไปเท่ากัน

## ดูรายงาน

1. ต้องเป็นบัญชีที่มีสิทธิ์ `payroll:export` ซึ่งผู้ดูแลฝ่ายบุคคลและเจ้าหน้าที่เงินเดือน
   มีอยู่แล้ว
2. ไปที่เมนู **เงินเดือน** แล้วกด **ส่วนต่างประกันสังคม**
3. เลือกปี รายงานขึ้นทีละคนทีละเดือน มีค่าจ้างที่ใช้คิด ยอดที่หักไปแล้ว ยอดที่ต้องหัก
   ตามเพดาน และส่วนต่างของลูกจ้างกับนายจ้าง พร้อมยอดรวมรายเดือนและทั้งปี
4. กด **ดาวน์โหลด CSV** เพื่อเปิดใน Excel การดาวน์โหลดถูกบันทึกไว้ในประวัติการใช้งาน

## อ่านรายงานอย่างไร

- นับเฉพาะรอบที่จ่ายแล้ว และรอบในงวดที่ล็อกหรือปิดแล้ว รอบที่ยังแก้ได้ไม่อยู่ในรายงาน
  เพราะคำนวณใหม่แล้วจะได้เพดานใหม่เอง
- ลูกจ้างรายวันที่จ่ายสองงวดต่อเดือน รวมสองงวดเป็นเดือนเดียวก่อนเทียบเพดาน
- คนที่ไม่ได้อยู่ในระบบประกันสังคมไม่อยู่ในรายงาน คนที่หักครบแล้วก็ไม่ขึ้น
- สลิปที่คำนวณก่อน Cwork เก็บค่าจ้างฐานประกันสังคมไว้ จะคิดค่าจ้างจากรายการในสลิป
  และมีป้ายบอกไว้ ควรตรวจกับสลิปจริงอีกครั้ง
- ปีที่ยังไม่มีรอบที่ล็อกหรือจ่าย รายงานจะว่าง

## รายงานนี้ไม่ใช่อะไร

รายงานนี้เป็นตัวเลขช่วยเตรียมชำระส่วนต่าง **ไม่ใช่แบบยื่น** และไม่ได้แก้รอบเงินเดือน
ใดเลย จะชำระส่วนต่างกับสำนักงานประกันสังคมเมื่อไรอย่างไร และจะหักคืนส่วนของลูกจ้าง
หรือไม่ ฝ่ายบุคคลต้องตัดสินเองหรือสอบถามสำนักงานประกันสังคม
